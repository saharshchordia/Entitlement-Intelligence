# Entitlement Intelligence

Static GitHub Pages package for entitlement intelligence memos, evidence tables, transcript materials, workbook outputs, and repeatable research methodology.

Open `index.html` for the published memo index.

Published pages:

- Jackson County, Georgia I-85 Industrial Entitlement Landscape
- Flowery Branch, Georgia I-985 Industrial Entitlement Landscape
- Jurupa Valley City Council IOS / Trucking / M-H Eligibility Memo
- Municipal entitlement hardening methodology and database model

Supporting CSVs, transcript summaries, source-audit tables, selected public-record HTML files, and rendered workbook previews are included where practical.

Large audio/video clips, local transcription environments, and runtime dependency folders are intentionally excluded from git.
